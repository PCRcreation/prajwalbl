# Prajwal B L – Portfolio Website
Files: index.html, style.css, script.js, images/

## Customize
1. Photo: replace images/profile.jpg to change the picture.
2. Skills, projects and typing roles: edit the lists at the top of script.js.
3. Email and LinkedIn: edit the Contact section in index.html.

## Publish on GitHub Pages
Upload all files to a repository, then Settings > Pages > Deploy from branch: main, folder: / (root).

## Note
The contact form only gives on-page feedback. Use a service like Formspree or a backend to receive real messages.
